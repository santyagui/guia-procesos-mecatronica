# Guía de Procesos Académicos — Ingeniería Mecatrónica UPS

Sitio web adaptable para consultar trámites académicos de Ingeniería Mecatrónica de la Universidad Politécnica Salesiana, Sede Quito.

## Publicación

El proyecto está preparado para publicarse automáticamente con GitHub Pages cada vez que se actualiza la rama `main`.

## Desarrollo local

Requiere Node.js 22 y pnpm 10.

```bash
pnpm install
pnpm dev
```

Para comprobar la versión de producción:

```bash
pnpm build
```
